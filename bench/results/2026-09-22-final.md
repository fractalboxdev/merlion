## Speed

The bench-run timings are single runs on a host with load average 3.4–7.4 and are not comparable across runs. The paired figures time each diagram as the minimum of 9 alternating `--batch` runs of each binary over the 384 renderable diagrams:

| Binary | p50 ms | p95 ms | Mean ms |
|---|---|---|---|
| `df1675b` (baseline) | 0.099 | 0.326 | 0.163 |
| `c69a4c4` (layout round 2, before P2) | 0.108 | 0.437 | 0.202 |
| `3f575ba` (P2, before the fixes below) | 0.126 | 0.436 | 0.221 |
| `ef34759` (final) | 0.119 | 0.422 | 0.210 |

The p95 rise comes from the layout work before P2 (`df1675b` → `c69a4c4`). P2 adds about 0.01 ms at p50 through the larger embedded style; the final build is faster than P2 before the fixes at every percentile.

## Stylesheet parity

`pnpm bench parity --require-rsvg`: 388 rendered diagrams (384 compat + 4 role fixtures; 6 compat diagrams fail to parse on both paths) × 2 themes of `bench/fixtures/parity.css` (`:root`, `dark`), 19,724 reference elements.

| Target | Compared | Mismatches |
|---|---|---|
| Baked SVG, no host CSS | 78,896 properties | 0 |
| Baked SVG, `<style>` removed | 78,896 properties | 0 |
| rsvg-convert 2.62.2 | 33,970 pixel samples + 4,928 text runs | 0 |

Text runs are compared by glyph colour inside each run's box (±8 per channel). The same gate run on the role fixtures with the build before role label rules dropped `:where()` reports 8 mismatches: every toned edge label and cluster title, in both themes. All four named themes of `merlion-themes.css` bake with no warning.

## Output changes since P2 landed

Layout, the layout hint and every coordinate are unchanged by the P2 fixes: all 384 compat renders are byte-identical before and after them. Among the test fixtures, `styled-classes.mmd` changes (its `classDef ok` / `warn` labels return to #1f2328 because a same-named `classDef` now replaces the built-in role), and `demo/roles/two-tier-roles.mmd` changes (role label selectors without `:where()`).

## Failures

Unchanged from the baseline. Merlion: 3 × `E002 expected a link, &, ; or a newline, found .`, 2 × `E002 expected a node id, found -`, 1 × `E002 expected the end of the link label`. mermaid-dagre and mermaid-elk: 1 × `Parse error on line 4`.
